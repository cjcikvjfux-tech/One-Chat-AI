# One Chat AI 🤖💬

**تطبيق محادثة ذكاء اصطناعي احترافي متكامل**

A professional, feature-rich AI chat application with voice support, multi-language interface, and secure backend architecture.

## ✨ المميزات الرئيسية | Key Features

### 🗣️ الاتصالات | Communication
- ✅ محادثة نصية سلسة | Text Chat
- ✅ محادثة صوتية مباشرة | Voice Chat (Speech-to-Text & Text-to-Speech)
- ✅ دعم الصور والملفات | Image & File Upload & Analysis
- ✅ معالجة الأخطاء الاحترافية | Professional Error Handling

### 🌍 اللغات والتصميم | Languages & Design
- ✅ العربية 🇸🇦 | English 🇬🇧 | Français 🇫🇷
- ✅ تصميم ديناميكي للهاتف والكمبيوتر | Responsive Mobile & Desktop Design
- ✅ وضع ليلي وفاتح | Dark & Light Mode
- ✅ واجهة حديثة وسلسة | Modern & Smooth UI

### 🔐 الأمان والخصوصية | Security & Privacy
- ✅ Backend آمن لحفظ مفاتيح API | Secure Backend for API Keys
- ✅ بدون مفاتيح سرية في Frontend | No Secrets in Frontend
- ✅ معالجة آمنة للبيانات | Secure Data Handling
- ✅ مصادقة وتسجيل دخول | Authentication System

### 💾 إدارة المحادثات | Chat Management
- ✅ حفظ المحادثات تلقائيًا | Auto Save Conversations
- ✅ البحث والفلترة | Search & Filter
- ✅ مشاركة المحادثات | Share Conversations
- ✅ تصدير PDF | Export to PDF

### 🤖 نماذج الذكاء الاصطناعي | AI Models
- ✅ دعم OpenAI (GPT-4, GPT-3.5)
- ✅ دعم Google Gemini
- ✅ دعم Anthropic Claude
- ✅ اختيار النموذج الديناميكي | Dynamic Model Selection

---

## 🛠️ التكنولوجيا المستخدمة | Tech Stack

### Frontend
- **Framework:** React 18 + TypeScript
- **Styling:** Tailwind CSS + Framer Motion
- **State Management:** Redux Toolkit
- **Voice:** Web Speech API + Howler.js

### Backend
- **Runtime:** Node.js + Express
- **Database:** MongoDB
- **Authentication:** JWT
- **API Integration:** Secure Proxy Pattern

---

## 🚀 البدء السريع | Quick Start

```bash
git clone https://github.com/cjcikvjfux-tech/One-Chat-AI.git
cd One-Chat-AI
npm run install-all
cd backend && cp .env.example .env
cd ../frontend && cp .env.example .env.local
cd ..
npm run dev
```
